Orchestration, Automation & Containers

The platform runs on Incus as a unified hypervisor and container runtime, supporting both VMs and LXC containers. Infrastructure is provisioned with Terraform for declarative network resources and host configuration, and managed with Ansible for idempotent, agentless system provisioning and drift remediation. Network segmentation is enforced at the switch layer via VLANs, with firewall policies applied per-segment.

Monitoring & Observability

Full-stack observability is provided by Prometheus for metrics collection and Loki for log aggregation, with network device logs shipped directly into Loki. Traffic observability across the network is enabled through sFlow, providing visibility into layer 2/3 flows without agent-based overhead.
