My local AI inference and development setup. Building a development process around a 100% local toolchain has a host of benefits:

  • Deeper understanding of how the AI toolchain fits together. A better architectural understanding, paired with real-time observability, helps me choose new models and efficiently tune the overall toolchain.
  • Greatly reduced operating cost. Running at the cost of electricity alone opens up a huge set of possibilities that aren't practical when paying per token or dealing with strict token limits.
  • Much better default observability.
  • A fully secure environment that protects against accidental or malicious access to client proprietary data and the wider network.

Hardware

GPU: Jetson Orin — 64 GB unified memory, compact, power-efficient inference hardware running llama.cpp.

The default model is Qwen3.6-35B-A3B-UD-Q6_K — 35 billion parameters, Q6 quantization, using a MoE (Mixture of Experts) architecture, with a context window of 131,072 tokens.

New models are made available via a mounted Samba share.

Interface

OpenCode — the TUI/GUI harness that provides the general interaction layer for local AI workloads. It handles session management, tool execution, and agent orchestration.

A library of Skills and MCP servers help ensure prompts receive the right context.

A custom microphone integration handles audio input — see the text-to-speach repository on GitHub.

Agent definitions are managed alongside the rest of the dotfiles using Chezmoi.

Networking

Isolated VLANs: AI hosts, tools, and related services are completely segregated from the rest of the network and the internet. This protects against misbehaving software and keeps proprietary project data safe. The isolation also works around some of the inherent permission limitations of current AI toolchains.

Monitoring & Metrics: Real-time metrics are collected across the network, services, and hosts to maintain both a general and AI toolchain specific visibility.

Fully Automated: Network configuration and management is entirely automated through Terraform and Ansible.

See the Home Lab page for the full network topology.
